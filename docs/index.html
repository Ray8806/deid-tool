去識別化工具

個資遮蔽 · 可還原

貼上文字,一鍵移除身分證、電話、地址、姓名等個資。所有處理都在你的瀏覽器內完成,不上傳、不連線。

  • 身分證
  • 手機 / 市話
  • Email
  • 地址
  • 日期
  • 信用卡
  • 病歷號
  • 姓名

開始使用

密鑰(hash 模式用,請自行保管)
輸入
輸出
    對照表(含原始個資,請妥善保管;還原時貼在這裡)
    已知姓名清單(一行一個,補強姓名偵測)

    沒有「姓名:」等關鍵字的人名無法自動辨識,把已知姓名放在這裡就會一併處理。

    規則式偵測不保證涵蓋所有個資,正式使用前請人工抽查輸出結果。

    為什麼可以放心

    LOCAL

    資料不離開瀏覽器

    沒有後端伺服器,處理全在你的裝置完成。關閉分頁後資料即消失。

    CSP

    禁止對外連線

    頁面以內容安全政策封鎖所有網路請求,即使有人想外傳也做不到。

    OPEN SOURCE

    原始碼公開

    規則與程式皆公開可檢視。另有 Python 版,支援 Excel、整欄處理與 NER 人名偵測。
